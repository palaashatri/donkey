# Donkey icon family

Original dimensional warm-stone donkey head and keyhole insignia, unique to the reverse-engineering application. Includes transparent source crop, 16–1024px PNGs, ICO, ICNS, wordmark and social banner. Supersedes rejected flat line-art SVGs. Resolutions larger than ~248px are scaled from the rendered concept sheet, not independently generated masters. This is a draft artwork proposal; app integration and OS launcher QA remain separate.
